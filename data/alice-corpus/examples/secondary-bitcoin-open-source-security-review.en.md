# Security review of open-source code

## Questions covered

- Is open-source software necessarily audited and secure?

## Short answer

Open code can be inspected by third parties and undergo independent reviews. This makes it easier to detect vulnerabilities.

## Explanation

- Transparency does not automatically guarantee security, but it allows inspection.
- Vulnerabilities can be detected by a broad community.
- Critical Bitcoin software should favor auditable code and verifiable signatures.
- Companies building on Bitcoin should integrate FLOSS and security practices.

## Limits and confusions

Open or auditable does not mean that a full audit has taken place or that no flaw exists.
