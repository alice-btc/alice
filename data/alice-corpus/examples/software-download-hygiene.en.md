# Downloading the right software

## Questions covered

- How to avoid a fake application?

## Short answer

Download hygiene aims to obtain the genuine software from an identified origin. A fake wallet can steal secrets or display a destination different from the expected one.

## Explanation

The project's domain, its distribution channel and the publisher's identity have to be verified. A sponsored result, a generic mirror or a link received by message does not prove the official origin. Pirated versions add a risk of modification and of missing maintenance.

For sensitive tools, the project may publish checksums or signatures. These elements allow additional checks, provided the right reference and the expected signing key are known.

## Limits and confusions

An app store does not rule out every imitation. Open source means that code is accessible, not that every downloaded file necessarily matches that code or that it is free of flaws. An HTTPS address protects the connection to the site visited; it does not certify that this site belongs to the project being sought.
