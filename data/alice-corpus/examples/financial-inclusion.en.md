# Access to payments

## Questions covered

- Which obstacles can Bitcoin reduce, and which remain?

## Short answer

Financial inclusion is effective access to tools for paying, receiving income, saving and trading. Being able to install a wallet is not enough to demonstrate that all of these uses become accessible.

## Explanation

Barriers can come from costs, required documents, opening hours, borders or account restrictions. An open payment network can reduce some of these frictions. For example, a person can receive a payment in a compatible wallet without waiting for a bank branch to open.

This example describes a technical possibility, not a documented individual success. To actually use it, one still needs a device, a suitable connection, basic knowledge, and people or merchants who accept the payment. A conversion can also require local liquidity.

## Limits and confusions

Volatility, custody, scams and loss of access to keys can create new difficulties. A simple but custodial service can reduce some barriers while reintroducing a dependency on the provider.

The assessment should look at cost, autonomy and concrete availability rather than the number of wallets alone. No uncorroborated testimony is used here. The rules on access or conversion in a given country must be verified separately.
