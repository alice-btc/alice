# The role of Bitcoin Core maintainers

## Questions covered

- Can the people in charge of the repository impose new rules on Bitcoin?

## Short answer

Maintainers notably handle merging contributions into the Bitcoin Core repository. Users always choose which software and which rules they run.

## Explanation

- Anyone can clone the repository and create a fork.
- Maintainers have a practical merging role, not the power to change the rules accepted by users.
- Pull requests can wait a long time for lack of qualified review.
- If the focal point becomes untrustworthy, another focal point can emerge.

## Limits and confusions

The ability to create a software fork guarantees neither its adoption nor its security.
